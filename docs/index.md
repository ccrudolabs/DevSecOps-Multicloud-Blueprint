# 🌐 DevSecOps Multicloud Blueprint

Bienvenido al portal técnico del blueprint multicloud desarrollado por Carlos Crudo – Cloud Solutions IoT®.

Este proyecto implementa infraestructura como código, seguridad automatizada, monitoreo de costos y prácticas DevSecOps sobre **AWS**, **Azure** y **GCP**, con herramientas como Terraform, GitHub Actions, tfsec, CodeQL, Trivy y más.
